# NodeScope 开源验收

1. 当用户全新克隆仓库时，应可按中英文 README 安装并启动本地 Web；页面依赖本地提供，不请求第三方 CDN。
2. 当服务探针遇到挑战页、5xx、非预期页面或网络失败时，应显示未知或失败，不能推导为可用或区域封锁。
3. 当浏览器读取列表、进度、编辑和重测响应时，不应收到代理凭据；YAML 导出仍应保留可导入的完整节点配置。
4. 当其他网站尝试访问本地服务时，应拒绝跨站请求和非本地 Host；合法本地 UI 和 Clash 订阅更新应可正常使用。
5. 当用户下载检测报告时，应默认隐藏 IP 和节点名，且从白名单构建、不含订阅配置、凭据或原始错误。
6. 当运行检测时，应保留本地历史且默认不自动提交到 Git；本地历史、配置、导出、日志和原始截图不得进入公开仓库或公开 Git 历史。
7. 应保留原作者和 GPL-3.0 许可证，注明借鉴来源；离线测试与 CI 应可复跑，发布后核对实际公开内容。
