# 设计

沿用 FastAPI + Alpine.js + CodeMirror 及现有 CLI，不重写检测引擎。新增独立的请求边界、公开响应过滤与报告模块；原始代理配置只在服务端状态中用于 YAML 导出。服务探针使用明确成功/封锁信号，HTTP 错误和挑战页进入 unknown/failed。

从源码白名单建立独立仓库，保留完整 LICENSE 和上游引用，不复制原仓库 `.git`、用户配置、真实历史和截图。依赖限定兼容范围，固定前端资源并保存许可证；用 pytest 发现全部测试，在 Windows / Linux、Python 3.10 / 3.12 运行 CI。

报告从限定指标构造，默认匿名节点名、移除 IP，不输出任意原始字符串。Web 仅绑定回环地址，校验 Host、Origin 和 Sec-Fetch-Site，禁止跨站访问；同源 UI、命令行和 Clash 客户端更新无需额外登录。

验证层次：离线逻辑、HTTP 边界、假控制器完整工作流、真实浏览器、本地进程与公开仓库检查。未经验证的服务实际可用性、用户正在使用的 Clash 配置恢复和所有平台实测不得宣称完成。
