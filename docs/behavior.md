# 行为与数据口径

默认双击入口是 `一键检测当前订阅.cmd` / `start.cmd`，自动准备 CLI 环境并运行当前订阅检测，默认附带 `--unlock`。它们不启动 Web。`web.py` 与下述 Web API 是可选高级入口，需额外安装 `requirements.txt`。

`pure_score` 表示污染度，越低越好，风险贡献为 `int(pure * 0.5)`。综合风险参考 abuse、IPQS、Tor、机房与地区一致性等信号；proxy / VPN 加分要求至少两个来源一致。DNSBL 真命中触发至少 90 分，Spamhaus 拒查码不算命中；未知不是 0。

DNS 泄漏、IPv6 与服务访问只作展示，不计入污染度与综合评分，不污染 IP 缓存。WebRTC 需要用户主动点击，未执行不能宣称无泄漏。

ChatGPT 的明确 `unsupported_country` 不会被 favicon 成功推翻。Claude 的 403 挑战页不是成功，Gemini 同意页不是区域封锁，Netflix 注册页不是完整片库。限流、5xx、异常页面和网络失败保留未知/失败。探针会随站点变化失效，绿色符号也不证明登录、付费资格、真实模型调用或当地政策允许使用。

并行检测临时注入 listeners，退出恢复基础配置与 selector 选择；无法取得完整安全基础配置时回退串行。串行暂时调整模式和选择。这会影响连接，强制终止进程可能来不及恢复。

停止后，配置恢复完成才释放占用；新检测、重测、节点编辑和删除在此之前返回 409。两次重测也互斥。

列表、SSE、编辑与重测响应不含 `proxy_config`；YAML 导出仍保留可导入的完整配置。Web 稳定链接为 `/api/export/subscribe`，一键入口为 `127.0.0.1:57520/checked_latest.yaml`，服务必须保持运行。

匿名报告只包含限定指标、匿名节点名，不带 IP、地区/ISP 自由文本、原始错误、地址或密钥。`null` 表示未测到。真实历史含节点名和出口 IP，默认只写本地忽略目录，不自动提交。显式启用自动提交还需使用者调整忽略规则并自行评估公开风险。

本地页面资源不依赖 CDN；真实检测仍需访问外部站点。
